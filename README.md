# 🍽️ Food Tree – Restaurant Website (Frontend Only)

## 📌 Project Overview

"Food Tree" is a static restaurant website developed using **HTML** and **CSS**. This was our first team-based frontend project during the **2nd year of B.Tech** as part of the **ProjectNest Program** conducted by our **college hostel management**.

As a **team leader** of Team 2 (6 members), I guided the development process and collaborated on ideas, structure, and design. The project took around **2 months** to complete and gave us strong hands-on experience with frontend technologies.

---

- 👨‍👩‍👧‍👦 Built by a team of 6 students (out of 12 roommates split into 2 teams)
- 💻 Developed using **only HTML and CSS**
- 🧠 Guided by **IIITH mentors**
- 🏆 Completed successfully with **certificate** and I received a **₹1000 reward** as team leader

---

## 🌟 Key Features

- **Home Page** – Landing screen with project name and register link
- **Login & Registration** – Static forms with HTML validations and UI
- **Menu Page** – Showcases various food items using responsive cards
- **Veg Menu Page** – Separate navigation for vegetarian items
- **Order Page** – Food ordering static form with input validation
- **Payment Page** – Placeholder for card details input
- **About Page** – Description of services and food quality
- **Contact Page** – Social media, email, and contact numbers
- **Thank You Page** – Final screen with appreciation message
